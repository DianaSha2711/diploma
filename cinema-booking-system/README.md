# Кинотеатр - Система бронирования билетов

Веб-приложение для бронирования билетов в кинотеатре с клиентской и административной частями.

## Стек технологий

### Frontend
- **HTML5** - структура страниц
- **CSS3** - стилизация с кастомными свойствами (CSS variables)
- **Bootstrap 5.1.3** - UI компоненты и сетка
- **Font Awesome 6** - иконки
- **JavaScript (ES6+)** - логика приложения

### Основные библиотеки
- **Bootstrap JS** - модальные окна, тосты, выпадающие списки
- **QRCode Generator** - генерация QR-кодов для билетов

### Архитектура
- **Модульный JS** - разделение на классы и модули
- **LocalStorage API** - хранение сессий и данных пользователя
- **REST API** - взаимодействие с бэкендом

### Классы JavaScript
- `CinemaAPI` - работа с API (получение фильмов, залов, сеансов)
- `AuthManager` - управление аутентификацией
- Компоненты административной панели

### Особенности реализации
- Адаптивный дизайн для мобильных устройств
- Кастомные стили с градиентами и тенями
- Интерактивная схема зала с выбором мест
- Система дат для выбора сеансов
- Генерация электронных билетов с QR-кодами
- Ролевая модель (администратор/клиент)
